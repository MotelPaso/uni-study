# Clase 1   
Usaremos SQL como lenguaje para armar nuestras bases de datos.   
Pero antes de crear una base de datos, se deben crear unos modelos para definir las relaciones entre los objetos/datos.   
## Modelo Entidad Relacionamiento (MER)   
Es el modelo conceptual de los datos, se usa en un etapa temprana de planificacion de la base de datos.   
Ordena los datos basados en un ambiente real, como los datos de un empleado y como se relacionan con un departamente. Esta pensado en forma muy macro, sin preocuparme demasiado con los tipos de datos (int, string, etc).   
### Entidad:   
Es basicamente una clase.   
### Relacionamiento:   
Como se relacionan las entidades, existen varios tipos de relacionamiento, 1 a 1, 1 a muchos, muchos a muchos, es similar a un diagrama de clases
