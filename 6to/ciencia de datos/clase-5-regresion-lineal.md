# Dato
Tiene etiquetas y atributos, donde los atributos son las variables de entrada y etiquetas las de salida.

$$
\text{Etiquetas = } \hat y\qquad
\text{Atributos = } x
$$

# Tipos de aprendizaje
Se diferencian en lo que devuelve, se usa regresion sobre valores continuos, clasificacion sobre valores discretos.
### Aprendizaje supervisado
Se basa en un dataset e intentamos encontrar una funcion que recibe los atributos y me devuelve una etiqueta, el vector tendra tantas columnas como tenga atributos.

### Aprendizaje no supervisado
Se usan todas las columnas

## Regresion lineal
Se tiene que definir una relacion lineal como
$$
y = mx +b
$$
Donde y es la etiqueta a predecir
