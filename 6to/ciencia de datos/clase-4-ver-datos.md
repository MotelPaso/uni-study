# Clase 4: Ver Datos   



Existen dos tipos de visualizacion, exploracion y presentacion:   
### Exploracion:   
Sirve para revisar como se comportan realmente las variables.    
### Presentacion:   
Es como mostramos las variables en base a una "verdad" que yo quiero mostrar.   
## Tipos de datos   
Cualitativa, de categorias o factores, que clasifican o jerarquizan los datos, o cuantitativa, de cantidades intervalos, discretas o continuas, que miden o cuentan los datos.   
### Variables nominales:   
Solo se puede sacar la moda, que es el dato que mas se repite. Un ejemplo puede ser el genero de una persona,    
### Variables ordinales:   

Son nominales, pero ademas indican un orden o jerarquia entre los datos, como alto, medio y bajo. Provienen usualmente de apreciaciones subjetivas de las personas.   

--- 
### Variables de intervalo:   
Son datos ordinales, pero no poseen un cero absoluto, sus valores son relativos, depende de la escala. Un ejemplo es la escala Celsius.   
En estas se pueden usar todas las operaciones estadisticas, media, mediana, moda, rango, etc.   
### Variables de razon o proporcion:   
Son variables de intervalo, pero cuentan con un 0 absoluto. El 0 significa que no existe el valor, o no tiene un valor agregado, como la edad, el peso o el volumen. Pueden ser continuos o discretos.    
# Tipos de Visualizaciones:   
Existen varias dimensiones, en una dimension tenemos graficos de barras, sirven solo para variables nominales o ordinales.
graficos de torta sirven principalmente de forma preeliminar, debido a que tienen una vista sesgada, donde solo se muestra la proporcion general de los datos.   
grafico de dispersion tiene dos variables y muestran que tan dispersos estan los datos en base a esas dos variables, una en el eje X y otra en el eje Y, no se deben usar cualitativas.   
un mapa de calor muestra la densidad de los datos, donde se concentran.
