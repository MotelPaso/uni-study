# Clase 1: Inicial   
## Requerimientos de Software:   
Lo que nos piden que el sistema deberia hacer, se dividen en funcionales (hacer) y no funcionales (cualidades).   
Algunos ejemplos de no funcionales es el desempeño, disponibilidad, capacidad, tolerancia a fallas y seguridad, privacidad, interoperabilidad.   
## Testing de Software:   
Verifican si un programa presenta un resultado esperado al ser probado con tests.
Pueden ser manuales o automatizados.   
Existen varios tipos de test, test unitarios.   
   
## Procesos de desarrollo de software:   
Define las actividades que deben ser seguidas para contruir un sistema   
### Waterfall (cascada):   
Como el desarrollo de software cambia con frecuencia, el metodo waterfall quedo obsoleto por que hacia cada paso lentamente, como la ingenieria tradicional.   
### Metodologia agil:   
Es un modelo basado en la construccion iterativa, donde se trabajaba sobre un MVP, haciendo pequeños ajustes sobre la marcha.   
## Tipos ABC de sistemas:   
### Sistemas C:   
Son sistemas peque;os, no se beneficia de lo que vamos a estudiar.   
### Sistemas B:   
Sistemas importantes para una organizacion promedio, el no usar las tecnicas genera "technical debt" que hara el trabajo siguiente del sistema muy complejo   
### Sistemas A:
